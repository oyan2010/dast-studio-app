# Dast Creative Studio & Admin Portal 🎨

A modern creative studio showcase and administration platform built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

---

## 🌟 Key Features

- **Studio Showcase**: Sleek landing page featuring studio projects, service offerings, and creative works.
- **Admin Management Dashboard**: Dedicated admin panel for managing portfolio items, incoming inquiries, and media content.
- **Responsive Layout**: Designed with Tailwind CSS utility classes ensuring smooth mobile and desktop rendering.
- **Fast Build & Dev**: Powered by Vite with Hot Module Replacement (HMR).

---

## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/oyan2010/dast-studio-app.git
   cd dast-studio-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
